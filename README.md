# Clover Halloween

Clover Halloween is a Minecraft plugin that adds a spooky twist to your gameplay. When players break crops, they have a 1% chance to find a Halloween candy. Players can use these candies to purchase special items in the Halloween shop, including the Halloween Scythe, a powerful netherite hoe, the Halloween Treat, a golden apple, and the Bat Scepter, which summons a bat every 30 seconds.

## Install

1. Download the plugin JAR file from the releases page.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. Break crops to collect Halloween candies.
2. Use the `/halloween shop` command to open the Halloween shop.
3. Spend your candies on the available items.
